# 오늘의 고양이

실제 인터넷에서 사용되는 고양이 밈 15장을 직접 확인해 고른 랜덤 추천 사이트입니다. 사진과 소스 파일 모두 이 폴더에 저장되어 있습니다.

## 열기

`public/index.html`을 더블클릭하면 서버 없이도 열립니다. 또는 Node.js 22 이상에서:

```sh
cd /Users/kimhyeyoon/Desktop/todays-cat
npm start
```

접속: http://localhost:3001 — 이 컴퓨터 전용 주소입니다. 서버가 실행 중일 때만 이 URL로 접속할 수 있습니다.

## 기능

- 랜덤 추천: 첫 사진부터 일반 사진 70% / 짧은 문구 짤 25% / 글이 많은 짤 5% 확률로 선택합니다. 글 있는 짤의 총 추천 확률은 30%입니다. 긴 채팅이나 여러 줄의 긴 문구가 있는 4장은 후순위로 분류했습니다. 각 그룹 안에서는 한 바퀴 동안 중복 없이 표시하며 직전 사진과도 연속 중복되지 않습니다(재접속 시 브라우저 저장 가능 조건).
- 문구 포함 짤 6장 추가. 이미지 속 기존 문구를 편집하거나 삭제하지 않습니다.
- 버튼 또는 스페이스바로 다음 사진 표시
- 즐겨찾기 저장/취소, 사진만 있는 저장 목록
- 분홍색 도트 배경, 투박한 버튼, 아날로그 창 디자인
- Google 이미지와 Pinterest에서 현재 고양이 관련 사진을 찾는 외부 검색 링크
- 모바일 화면, 이미지 실패 처리, 키보드 조작

## 연동 범위

**Google/Pinterest 검색 링크 연결이며, 두 서비스의 실시간 이미지 수집 API 연동은 아닙니다.** Google Custom Search JSON API는 신규 고객을 받지 않으며 기존 고객도 2027-01-01까지 이전해야 합니다. Pinterest API는 등록 앱과 사용자 승인·토큰이 필요합니다. 별도 인증 없이 즉시 쓸 수 있도록 로컬 큐레이션 컬렉션과 검색 링크를 구현했습니다.

- https://developers.google.com/custom-search/v1/overview
- https://developers.pinterest.com/docs/getting-started/set-up-authentication-and-authorization/

## 이미지 출처

`SOURCES.json`에 사진별 출처 게시물과 이미지 주소가 있습니다. 수집처는 Imgflip이며 사진의 원저작권은 각 권리자에게 있습니다. 이 파일이 이미지 재배포 라이선스를 부여하지는 않습니다. 사진에 별도 제목이나 설명을 붙이지 않습니다.

개인용 로컬 사이트입니다. 외부 공개 배포는 하지 않았습니다. 고양이 일러스트, 스톡 느낌 사진, 인형 사진은 컬렉션에서 제외했습니다.

## 확인

`npm test`로 랜덤 순환의 중복 방지, 단일 항목 처리, 사진 파일 존재 여부를 검증합니다. 브라우저 자동화 연결이 없어 실제 브라우저 화면 검증은 수행하지 못했습니다.
